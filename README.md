## How do I use this?
It's currently deployed on [vercel](https://butterfly-tracker.vercel.app/) and it can work on your phone.

It should be self explanatory, but you can:
1. On the home page you can count butterfly by tapping on the buttons (tapping on image increase count) + u can filter the butterfly based on name
2. On the list page you can see the butterflies as a list and edit or even reset the local database you have
3. On the details page you can enter the survey details liked date, time, transect, etc that will be used in the results later
4. In the results page you can see a text report on the survey and you can copy it or reset the whole survey
